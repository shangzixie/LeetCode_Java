## template 3

这里，给一个二维数组grid，每个元素都是0或1。这里每次从`(start_x, start_y)`开始，记录连接在一起的1的个数（岛屿的面积），并将遍历过得1置为idx（idx大于1）。

![181](/Image/181.png)
![182](/Image/182.png)

上图中，第二个图为延迟标记。延迟标记会导致同一个邻居可能被多个相邻点重复加入队列，结果在队列中出现重复，进而导致 size 计数错误（重复计数）。

例如：

```
[[1, 1],
 [1, 1]]
```

第一次while循环：
弹出`(0, 0)`， 加入队列`(0, 1)`和`(1, 0)`，此时队列为：`deque([(0, 1), (1, 0)])`

```
[[2, 1],
 [1, 1]]

```

第二次while循环：

弹出`(0, 1)`，加入队列`(1, 1)`，此时队列为：`deque([(1, 0), (1, 1)])`

```
[[2, 2],
 [1, 1]]
```

第三次while循环：

弹出`(1, 0)`，加入队列`(1, 1)`，此时队列为：`deque([(1, 1), (1, 1)])`

```
[[2, 2],
 [2, 1]]
```

这时候，队列中有两个`(1, 1)`，这是因为延迟标记，导致弹出`(0,1)`时候加入了`(1, 1)`，弹出`(1, 0)`时候又加入了`(1, 1)`。

详细请做[leetcode 827](BFS/Making_A_Large_Island/readme.md)
